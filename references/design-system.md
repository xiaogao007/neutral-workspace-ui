# 中性工作台设计规范

## 颜色与语义

| 角色 | 浅色默认 |
|---|---|
| 外壳 / 导航 | `#f7f7f7` |
| 页面 / 表面 | `#ffffff` |
| 微弱分组 / hover | `#fafafa` / `#f1f1f1` |
| 正文 / 次级 / 辅助 | `#262626` / `#595959` / `#737373` |
| 边框 / 强边框 | `#ebebed` / `#dedee2` |
| 主按钮 / hover / 文字 | `#262626` / `#111111` / `#ffffff` |
| 强调 | `#4c4cfa` |
| 强调选择文字 / 弱底 / 边 | `#4c4cfa` / `#f6f6ff` / `#e1e1ff` |
| 中性选择文字 / 弱底 / 边 | `#262626` / `#eaeaec` / `#c6c6cb` |
| 焦点 | `#386fc0`，2px outline，默认offset -2px |
| 成功文字 / 弱底 | `#26764c` / `#eff7f1` |
| 警告文字 / 弱底 | `#94651d` / `#fcf5e8` |
| 危险文字 / 弱底 | `#ad403a` / `#fdf0ef` |
| 画布 / 点 | `#f2f2f2` / `rgba(0,0,0,.08)` |
| 媒体预览 / 前景 | `#111318` / `rgba(255,255,255,.92)` |

默认采用强调选择态。信息密集的列表、表格或表单可采用中性选择态；同一选择组不要混用。切换选择风格不改变主按钮、状态色或焦点色。

辅助文字仍需可读，低透明度灰色只用于禁用或非必要装饰。状态不能只用颜色表达。图表可使用紫 `#8c77b3`、绿 `#7a9582`、蓝 `#5b80ae`、桃 `#bb8666`，并提供图例、标签或数据访问方式。

暗色是可选视觉变体：页面 `#070a12`、导航 / 表面 `#151923`、正文白88%、次级白65%、辅助白60%、边框白12%、强调 `#9292ff`、焦点 `#8ab4f8`。深灰主操作在暗底上反白。完整映射见变量文件，不自行反转媒体颜色或图片。

## 字体、间距与几何

使用系统无衬线栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。字体跟随内容语言。数字指标、时间和金额使用tabular-nums；ID或代码局部可用等宽字体，普通标签不用整页等宽或全大写字距样式。

| 层级 | 字号 / 行高 | 字重 |
|---|---|---|
| 辅助 / 元信息 | 12 / 20px | 400 |
| 正文 / 控件 | 14 / 22px | 400–500 |
| 卡片标题 | 16 / 24px | 500–600 |
| 区块 / 对话框标题 | 18 / 28px | 600 |
| 页面 / 编辑实体标题 | 24 / 32px | 600 |
| 指标 | 22–28px；窄屏19px | 600 |

14/22px适用于生产工具；长文阅读可用15px / 1.8。不将展示标题、价格大字或极小节点标签推广为正文。

间距使用4 / 8 / 12 / 16 / 20 / 24 / 32px。图标文字间4–8px，控件间8–12px，列表 / 网格12–16px，卡内16px，页面内距24px、窄屏16px。按左边缘和文本基线对齐。

| 组件 | 默认规格 |
|---|---|
| 标准 / 表单控件 | 高40px，横padding12–16px，radius10px |
| 紧凑控件 | 高32px，横padding12px，radius10px；仍用14px字 |
| 图标 | 常规16px，导航可20–24px；图标按钮桌面至少32px |
| Select菜单 | 与触发器外宽对齐，padding4px，radius10px；项至少36px |
| 分段导航 | 外高40px / padding4px / radius16px；项高32px / radius12px |
| 卡片 | radius16px，padding12–16px，1px边框 |
| 临时工具浮板 | radius20px，padding16px，gap12–16px |
| 对话框 | radius24px；默认宽560px、宽版680px，最大视口减32px |
| 对话 / 长输入容器 | radius24px，padding12–16px，内部按内容自适应 |

紧凑密度用于桌面筛选和工具条；长表单、主要提交优先40px。触屏按实际交互提供足够点击区域，可增加到44px；不靠缩小字号塞入信息。一个工具栏与它的下拉菜单保持一致的密度语言。

## 布局模式

以下宽高是起点，按目标任务、内容和设备调整；它们不要求创建原本不存在的导航、页面或辅助栏。

| 模式 | 结构与使用条件 |
|---|---|
| 应用工作台 | 72px窄导航 + 自适应主区；顶行约64–68px。浅灰外壳、白工作面，外留白8px，工作面16px圆角 |
| 列表 / 表格 | 导航和筛选靠近结果；工具栏可换行，表头弱灰，行hover浅灰；列表有界加载 / 分页沿目标数据契约 |
| 主从编辑 | 左列表约280–360px，右编辑自适应；需要时添加约360–400px上下文栏，窄屏纵向或可关闭详情 |
| 媒体网格 | `auto-fill/minmax`随内容减列；缩略图保持比例，列表cover、详情contain；主要操作不只在hover出现 |
| 画布编辑器 | 画布填剩余空间，工具栏与面板各自滚动；18–24px点距可随缩放调整；保留平移 / 缩放、节点选择和正文输入关系 |
| 步骤工作流 | 节点标题、输入、状态和输出有明确层级；只有真实步骤才编号或连线；节点尺寸由内容与缩放决定 |
| 阅读 / 设置 | 窄设置面板约680px，阅读正文约800px；自然纵向滚动，不强套画布锁高 |

导航语法表达层级：顶级范围可用分段；同级模块用下划线Tab；列表内类型或条件用轻量灰底筛选。没有三层导航时不为凑风格增加层级。

主区使用 `min-width:0`；需要内部滚动时建立完整 `min-height:0` flex/grid链。表格横向溢出只在表格容器滚动。不要通过固定所有祖先高度来强行填满屏幕。

## 组件配方

**按钮**：主按钮深灰 / 白字；次按钮白底细边；低强调按钮透明底、hover灰底。危险动作使用语义危险色且与安全主动作分开；实际确认条件沿业务契约。busy时原位置显示spinner与状态，尺寸不跳动。

**字段与Select**：默认白底细边，placeholder用辅助色，聚焦只在一个容器画2px蓝轮廓，内部input不重复画框。标签、帮助和错误在字段附近。自绘菜单同触发器宽、限高约320px、边缘避让、内部滚动；复用目标框架维护的可访问Select。只有接受系统弹出层外观时才选择原生控件，不把改了外壳的原生select误当自绘菜单。

**卡片与媒体**：普通卡片不加常驻阴影；选择用2px边或内描边且不改变几何。长名称单行省略时提供完整访问，金额和重要计数完整显示。加载 / 失败保留媒体框，只有媒体可轻微scale(1.03–1.04)，卡片不整体上浮。

**表格**：表头12–14px / 600，正文14/22px；普通行约48–56px，带缩略图约64px，按内容调整。sticky表头、选择、排序和分页服从现有实现，风格不改变数据导航或全选范围。窄屏局部滚动，核心对象和动作可达。

**弹层与侧栏**：菜单阴影 `0 8px 24px rgba(0,0,0,.12)`；dialog阴影 `0 16px 64px rgb(31 37 50 / 13%)`，padding24px、小屏16px；长内容在body滚动。模态有标题、焦点约束、Escape和焦点恢复。非模态上下文栏不因为有阴影就锁住背景。

**输入容器**：长输入或对话编辑区白底、大圆角、弱阴影，工具留在容器内，文字14/22–24px，自适应高度有上限后滚动。无此类任务时不用输入器装饰普通表单。

**反馈**：空态短标题加一句指引；无匹配提供清除条件；错误说明修正路径。复用目标应用已有Toast位置与时机，不另外引入一套；关键失败不能只用Toast。状态控件、消息和图标有可访问名称。

## 阴影、动效与滚动条

普通卡片用边框和留白。阴影只表达临时层级；必要浮板可用 `0 2px 12px rgba(0,0,0,.06)`。对话输入可用 `0 4px 20px rgba(0,0,0,.06)`，聚焦增强到 `.14`，不传播到每个输入框。

hover、颜色与边框默认160ms，tooltip淡入约120ms；尊重reduced-motion。避免非必要自动动画、整页渐变、玻璃拟态、满屏彩色指标卡和营销大标题。

滚动条可取6px、灰色圆头、hover加深，保留可见可操作性与高对比度适配。复用目标项目层级系统，不照搬任意z-index。

## 变量接入

主题与选择属性放在视觉根上，变化只影响其子树。密度也可在内部容器指定：紧凑页中的表单设为standard，即可恢复40px而不重置颜色。Portal内容在根外时，使用框架主题Provider或给Portal根复制相同属性。不要同时维护两套颜色常量。

```html
<main data-neutral-ui data-nw-density="compact" data-nw-selection="neutral">
  <!-- 列表与筛选使用32px -->
  <form data-nw-density="standard"><!-- 表单与主要提交使用40px --></form>
</main>
```

```css
.page {
  font: var(--nw-body-size)/var(--nw-body-leading) var(--nw-font);
  color: var(--nw-text);
  background: var(--nw-page);
}
.primary-button {
  min-height: var(--nw-control-height);
  padding-inline: 12px;
  border-radius: var(--nw-radius-control);
  background: var(--nw-action);
  color: var(--nw-action-text);
}
.primary-button:focus-visible {
  outline: 2px solid var(--nw-focus);
  outline-offset: -2px;
}
```

`data-nw-density="compact"`选择32px，`standard`恢复40px；子容器未指定时继承，视觉根默认40px。`data-nw-selection="neutral"`选择灰阶；省略时蓝紫。`data-nw-theme="dark"`选择可选暗色；选择风格与密度在暗色下仍然成立。示例只说明变量消费，不是完整按钮实现。
